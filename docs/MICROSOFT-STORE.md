# Microsoft Store

## Vorbereitung

Im Microsoft Partner Center den Produktnamen reservieren und die Paketidentität
abrufen.

Benötigt:

- Package/Identity/Name
- Package/Identity/Publisher

Diese Werte müssen vor Erstellung des Store-Pakets in die Manifestvorlage
übernommen werden.

## Architekturen

Das Store-Bundle enthält native Pakete für:

- x64
- ARM64

Für den direkten Download kann weiterhin die Universal-EXE verwendet werden.
